## Prospectively changing the final-support constraint

Past cycles apply an inherited common tissue mask after every model. This can
erase an otherwise correct label, regardless of the candidate's glass rule.
The three new envelope children explicitly own their native final support and
can restore tissue outside that old mask. Their class fields still use the
same original coarse observations and training weights. They may not create
new semantic IDs. They remove only photometrically white pixels, using H&E
alone, with no fine-reference input. Native support calculation is timed.

B23 is a separately labelled ablation control: J01 class evidence with the
native convex envelope as the actual final support. It isolates removal of
the inherited clip and is not selectable or counted among the15 innovations.

per image. The five historical parents keep exact native-mask parity with
cycle10 wherever frozen inputs are identical; every parent is rescored on the
new cohort under the same prospective scoring contract as its children.
No accuracy parity with cycle10 is claimed when the scoring contract changes.
Changed sampling requires a matched parent baseline. All23 outputs are visually reviewed, and
all qualified images remain required. Additional restored glass is a failure to inspect, not an
automatic benefit from a larger mask.

Common-support upper bounds remain diagnostics only for methods using that
support; they are not upper bounds for P10–P12/B23. Deleted positive reference

## Prospective binary-target scoring contract

The [OCELOT provider guide](https://lunit-io.github.io/research/ocelot_dataset/)
defines cancer, non-cancer background and unknown tissue labels. Non-cancer
is not an expert stroma class. PESO's negative target is non-epithelial;
ORCA's negative combines expert carcinoma exclusion and image-derived tissue
extent. For these explicitly declared broad negatives, our evaluation maps
saved-zero predictions on RGB-photometrically-white pixels to the negative
class for scoring only. This is our prospective task adapter, not a claim to
implement the provider's official metric. Non-white unassigned pixels remain
errors, deleted cancer/epithelium remains false-negative, every positive
reference pixel remains in the denominator, and reference0 stays ignored.
Saved masks remain background0. CAMELYON's detected non-tumor tissue does not
receive this broad-negative adapter. Historical signed scores are unchanged.
All parent/child comparisons, small-region reports and support bounds must
use the same contract. Differences from old cycle means are not method gains.
