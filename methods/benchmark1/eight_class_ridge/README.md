# Eight-class supervised Virchow2 head

This is the executed Chiamaka-local implementation of the revised Benchmark 1 development gallery. The source scripts are byte-identical to the audited version under `Bora/migration/benchmark1-eight-class-head-search-2026-11-12-v1/`. They expect the project's checksum-bound local input manifests and do not contain or download images or features.

The training-only search compares four prespecified CPU heads on 139,736 sampled Virchow2 tokens from 397 training images, with two source-group-disjoint folds. All 1,280 source channels remain in the reusable cache. The selection rule maximizes equal-dataset mean case macro IoU across BCSS, GCSS, IGNITE and TIGER, then chooses the faster candidate within 0.005 of the highest score. It selected one-versus-rest standardized contrasts, top 32 channels for each of eight classes, a stable union, and a class-weighted multiclass ridge head. The full training fit used 203 unique channels.

`search.py` implements the frozen fold comparison, `fit_final.py` fits the selected model, `validate.py` performs the one-time 87-image development evaluation, `polish.py` applies the existing Bora 1.5 µm contour and 400 µm² area repair, and `render_bw.py` makes eight monochrome response maps per case. The latter softmax is a relative display transform of ridge decision scores; it is **not calibrated probability**. Predictions are limited to roles annotated for the source dataset. All colored overlays share Bora's H&E tissue support for display; scores use unmasked predictions on expert-scored pixels.

The audited post-contour development mean case macro IoU is 0.701618 across 87 images and 0.615325 as the equal-dataset mean across the four multiclass datasets. These images were inspected during development, so this is not an independent test. The older 24-class joint/PLS blend scripts at the parent path are historical and are not the current gallery's supervised head. The Benchmark 2 public WSI pages currently retain the earlier eight-class logistic head pending a separate full-slide rerender.
