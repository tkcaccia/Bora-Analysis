Benchmark 1 · broad tissue labels

Browse 87 H&E development validation images with eight tissue labels selected from the 397 training images. The training-selected supervised Bora mask and its eight black-and-white Virchow2 responses appear with the expert and external methods on each image.

Training data · public expert masksValidation data · 87 images

Development evaluation. These 87 images were inspected during earlier method development and are not an untouched test. The eight-class label set and supervised model were selected on training images alone. Alveolar tissue, cartilage or bone, liver tissue, mucus/plasma/fluids, and muscle are unscored because they lacked enough independent training support; they are not treated as background. Broader labels change the scoring task, so compare scores only within this page.

PEsO reference correction. The 19 PEsO figures now show the original expert epithelium and a conservative, H&E-supported weak stroma proxy for some non-epithelial pixels. This proxy is not a pathologist annotation. All available prior-model scores on PEsO were recalculated against these same two reference classes; the former epithelium-only 100% score is withdrawn. The newly trained supervised Bora result is pending. KODAMA–Bora cannot be rescored on PEsO because its exact spatial mask is absent.

Broad-label results on the same H&E image

The legend names only classes in the reference mask or at least 1% of a displayed model panel. Model overlays use the same Bora H&E tissue support. The KODAMA–Bora spatial mask is unavailable in the curated local cache, so that panel is deliberately unfilled. Its frozen score remains available for the four original-reference datasets; PEsO's changed reference cannot be rescored from the old counts.

The displayed supervised Bora head selects 32 discriminative channels per class from the full 1,280-channel Virchow2 cache (203 unique channels), then fits a multiclass ridge classifier on the 397 training images. Four prespecified heads were compared on source-group-disjoint training folds using case macro IoU and CPU time; no development image was used for selection. The corrected PEsO-trained head is pending. KODAMA–Bora geometry and fastPLS naming were not refitted. Its original-reference scores remain a reanalysis of frozen counts for the other four datasets. External predictions were rescored on the displayed PEsO reference without retraining.

External method scores

U-Net and DeepLabV3+ use RGB H&E. VISTA-PATH uses external pretraining. MedSAM uses U-Net-derived boxes for tumor, stroma and necrosis. These methods have different output tasks; the cards do not establish a method ranking.
