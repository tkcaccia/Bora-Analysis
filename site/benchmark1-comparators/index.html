The color key beneath the figure includes the expert tissue classes and substantial predicted colors visible in this case. Every method overlay uses the same Bora H&E tissue support for background; the expert annotation is shown unchanged. Select the image to open it full size.

Both Bora values are image-level mean IoU over expert-present harmonized tissue classes. The unsupervised route first clusters image features and then names groups with fastPLS. The supervised route uses Virchow2 features and expert-masked training images; the dataset ontology gate restricts only its final class decision. Its unmasked prediction is scored after contour polish and nearest-neighbor alignment to the expert frame. Tissue-support clipping is for display and does not change scores.

External comparator results

U-Net and DeepLabV3+ were fitted on the same 397 training images using RGB H&E. VISTA-PATH uses external pretraining and a limited class map. MedSAM uses boxes from an earlier U-Net and predicts tumor, stroma, and necrosis only. Their score sets differ by method.
