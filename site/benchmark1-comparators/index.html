Training-selected Bora: start from 256 channels

A single set of 256 original Virchow2 channels was selected using only 397 training images and 1,192 expert-mapped training groups. This route starts with those channels before KODAMA, graph clustering, Bora's within-image 64-channel selection, mask fitting, and fastPLS tissue naming. Its fastPLS head was refitted on the same frozen training set using those channels. No evaluation image or whole slide supplied a feature-selection or classifier target. The historical training-group tile rule differs from this strict evaluation tile rule.

How to read the panels

BoraImage-derived groups followed by fastPLS class predictions. The classifier was trained under a different tile rule from this revised mask run.
Class-aware U-NetThis project’s U-Net takes RGB H&E tiles as input and was trained on 397 images paired with expert masks; no inference prompt. The black-and-white maps below are its class responses.
DeepLabV3+Supervised on the same frozen 397 training images and expert masks as U-Net; no inference prompt. Randomly initialized ResNet-50 backbone.
VISTA-PATHExternally pretrained. Only predeclared matched tissue classes are colored; unmatched classes are left uncolored. Source overlap cannot be fully excluded.
MedSAMPrompt-guided masks for tumor, stroma and necrosis only. Its boxes came from an earlier U-Net, not the expert or the U-Net panel shown here. Some cases received no box for a role.

Select the figure to open it at full size. The tissue-class color legend is printed on every figure. Uncolored regions in a model panel may be unmatched classes or absent predictions.

Scores are image-level mean intersection over union on the explicitly named expert-present or mapped roles. A missing score means the corresponding comparison was not defined for that image.

Combined tissue-class response mask

This is another view of the class-aware U-Net prediction in the comparison figure above, not an independent model. For this validation image, each pixel takes the class with the strongest of the 24 black-and-white U-Net response maps below. This mask uses distinct display colors; its legend lists only classes present here. Class numbers and names match the comparison figure above, whose display colors may differ. This is a display-resolution prediction made from compressed response maps, not an expert mask, a Bora region mask, or a native-resolution accuracy result. The model has no background class, so it assigns a tissue class even on glass or other non-tissue pixels.

Across the 87 cases, these two U-Net class masks agree at 97.0% of display pixels after resizing the original prediction. The differences reflect their tile blending and display processing. This agreement measures rendering consistency, not accuracy against experts.

Black-and-white response maps for every tissue classification

For this selected image, the 24 maps below show the frozen class-aware U-Net response for each tissue class. The model was fitted on the 397 training images and expert masks. Overlapping predictions are blended with tapered tile edges to avoid visible stitching lines. Each map uses the same scale: black means probability 0 and white means probability 1. Responses are model predictions; they are not expert annotations, Bora group responses, or accuracy scores. Display copies are at most 640 pixels on the long edge.
