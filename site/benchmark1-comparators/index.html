Benchmark 1: side-by-side model outputs

For each of 106 development evaluation images, compare the original H&E, expert annotation, Bora, U-Net, DeepLabV3+, VISTA-PATH and MedSAM in the same image frame.

Development evidence. These images were inspected during method development, so this gallery is not an untouched test. Scores below use different class sets for different tools and must not be read as one overall ranking. The older 116-image interactive display on the home page is a separate historical benchmark.

On the same 106 images and expert-present tissue classes, mean intersection over union was 0.204 for DeepLabV3+, 0.495 for the class-aware U-Net, and 0.164 for classic Bora. The training-selected Bora score is shown separately below. DeepLabV3+ and U-Net used the same 397 expert-masked training images; both Bora routes use image-derived groups and a tissue classifier. These figures are exploratory because the evaluation images had been inspected during Bora development.

Classic Bora: all 1,280 Virchow2 channels available at input

The first RGB image shows Bora's anonymous clusters. The second shows the same mask after fastPLS assigns tissue names. The H&E overlay helps inspect the cluster boundaries. All three use the same saved Bora geometry.

Across these 106 development images, the image-level means were 0.331 adjusted Rand index and 0.482 optimally matched IoU for anonymous groups on covered expert pixels. Bora groups reached 93.9% of expert-annotated pixels on average. The fastPLS name matched the expert-majority tissue in 46.8% of groups per image on average. These conditional scores describe different stages; the end-to-end tissue macro IoU on the full expert-present class rule was 0.164.

Training-selected Bora: start from 256 channels

A single set of 256 original Virchow2 channels was selected using only 397 training images and 1,192 expert-mapped training groups. This route starts with those channels before KODAMA, graph clustering, Bora's within-image 64-channel selection, mask fitting, and fastPLS tissue naming. Its fastPLS head was refitted on the same frozen training set using those channels. No evaluation image or whole slide supplied a feature-selection or classifier target. The historical training-group tile rule differs from this strict evaluation tile rule.

How to read the panels

BoraImage-derived groups followed by fastPLS class predictions. The classifier was trained under a different tile rule from this revised mask run.
Class-aware U-NetSupervised on the 397 training images with expert masks; no inference prompt.
DeepLabV3+Supervised on the same frozen 397 training images and expert masks as U-Net; no inference prompt. Randomly initialized ResNet-50 backbone.
VISTA-PATHExternally pretrained. Only predeclared matched tissue classes are colored; unmatched classes are left uncolored. Source overlap cannot be fully excluded.
MedSAMPrompt-guided masks for tumor, stroma and necrosis only. Its boxes came from an earlier U-Net, not the expert or the U-Net panel shown here. Some cases received no box for a role.
