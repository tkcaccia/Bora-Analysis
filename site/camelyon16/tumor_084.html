Every method panel uses the same H&E-derived display support. The reference panel shows all official code 1/2 pixels. The binary scores use those 6,729,265 known pixels; 4,119 (0.1%) lie outside the display support and remain in both score denominators. 104,761 known pixels are metastasis. Native and shared-support results remain separate.

Bora, U-Net and DeepLabV3+ were adapted using only tumor_093 and normal_093. MedSAM uses boxes from the adapted U-Net. VISTA-PATH uses a fixed broad “tumor” prompt, which is not metastasis-specific. KODAMA–Bora anonymous grouping was not fitted because 40,411 strictly admitted tiles across five slides exceed its 10,000-tile joint cap; it has no validated CAM tumor naming head.
