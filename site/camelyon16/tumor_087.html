All five workflows completed this slide. The official reference contains 10,141,104 known code-1/code-2 pixels; 11,151 are metastasis and 266,043 (2.6%) lie outside the reviewed display support. All scores use the same known-pixel denominator, including those outside support. Native output is primary; shared-support output is a separate sensitivity analysis.

Bora was fitted only on tumor_093. The class-aware U-Net and DeepLabV3+ checkpoints used tumor_093 only after Benchmark 1 pretraining. MedSAM received boxes from this one-slide U-Net; VISTA-PATH uses a released generic “tumor” prompt. These are configured workflow comparisons with different prompt dependencies and pretraining, not a controlled architecture ranking. Bora’s binary score margin threshold was selected on the tumor_093 training labels only (-0.1274); the tumor_087 reference was not used to tune it. The threshold increased recall but lowered tumor_087 IoU relative to the archived zero-threshold result.

Completion: five of five methods. See exact denominators, confusion counts, boundary and lesion metrics. This source-selected public-release slide does not estimate population performance; patient and center overlap with fitting remains unverified.

Contour fidelity: the exact scored Bora mask uses 4 µm pixels, a 6 µm contour pass and 2,000 µm² region cleanup. The downloadable review GeoJSON uses a guarded 3 µm global contour fit with oblique segments. Its minimum class raster IoU to the exact mask is 99.64%; scores use the exact raster. The interactive display uses a separate 12 µm smoothed review vector and omits 406 polygons below 0.02 mm² across both classes (2.479 mm², including 2.362 mm² of metastasis-like prediction). These visual edits do not change the saved Bora vector or the scores.
