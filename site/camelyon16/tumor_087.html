All five workflows completed this slide. The official reference contains 10,141,104 known code-1/code-2 pixels; 11,151 are metastasis and 266,043 (2.6%) lie outside the reviewed display support. All scores use the same known-pixel denominator, including those outside support. Native output is primary; shared-support output is a separate sensitivity analysis.

Bora was fitted only on tumor_093. The class-aware U-Net and DeepLabV3+ checkpoints used both tumor_093 and normal_093, plus earlier Benchmark 1 pretraining. MedSAM received boxes from that U-Net; VISTA-PATH uses a released generic “tumor” prompt. These are configured workflow comparisons with unequal training information, not a controlled architecture ranking.
