Native spot expression groups

Gene counts from 4,169 filtered in-tissue spots were aligned exactly to the source Visium spot barcodes and full-resolution pixel coordinates. KODAMA used 18,085 gene-expression features after per-spot library scaling, log transform and 30-component truncated SVD; the 35 measured antibody features remain in the preserved source and were not used for these gene groups.

Interpretation: These are anonymous exploratory gene-expression groups, not cell types or pathology labels. The official 10x source was immunofluorescence stained and its image was upscaled for display. No H&E Virchow2 features, Bora image refinement or class GeoJSON are claimed here. Four native spot centers at x = −17 pixels are retained in the downloadable table.
