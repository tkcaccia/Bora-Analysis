Reproduce and verify Benchmark 3

A practical guide to the breast, colorectal and tonsil Visium examples.

← Benchmark 3 results

Benchmark 3 asks whether image-guided refinement can turn spatial gene-expression spot groups into a registered tissue-region map. The published examples use expression groups as input. They do not demonstrate cell-level gene-expression localization or accuracy against independent anatomical masks.

1. Register 10x spots to H&E
2. Group expression profiles
3. Extract calibrated Virchow2 features
4. Refine group fields with Bora
5. Inspect mask and GeoJSON
What you can reproduce now: download and independently check all three final published GeoJSON outputs with a working standard-library script. You can inspect the same full-section views and nine crops on the result pages. The check takes Python 3, a network connection and at least 1 GB of free RAM for the largest GeoJSON; it needs no GPU.
Full inference rerun status: the public archive does not contain every historical full-resolution Virchow2 grid, frozen spot-group table and fitted field-model input needed to regenerate the three masks bit for bit. The clustering front ends are released, but their historical R and wsiTools environment is also needed. The commands below verify saved results; they must not be described as an end-to-end rerun.

2 · Verify the published outputs

  1. Install Python 3.10 or newer. No Python packages, R installation or model weights are needed for this saved-output check.
  2. Clone Bora-Analysis and run the verifier from its repository root. It downloads the three GeoJSON archives from their pinned Git revision, checks compressed and uncompressed SHA256 values and sizes, and inspects group IDs and geometry types.
git clone https://github.com/tkcaccia/Bora-Analysis.git
cd Bora-Analysis
python3 methods/benchmark3/verify_published.py \
  --provenance site/visium/FULLSECTION_PROVENANCE.json

3 · Inspect what the output means

  1. Open the breast, colorectal or tonsil page.
  2. Compare the original H&E, coarse expression groups, Virchow2 response view and final mask at the full-section overview. Then inspect a matched zoom. Each zoom is a crop of the same final section mask.
  3. Use the GeoJSON inspector or download the full native-coordinate GeoJSON. Its properties.value is the anonymous group ID. Do not interpret it as a cell type or an expert tissue class.

The GeoJSON check establishes output integrity and format. It does not recompute the reported spot-centre agreement or test tissue-boundary accuracy. In breast, the published tissue support visibly omits some pale tissue; an uncolored region there is a limitation of the output.

4 · Inputs required for a new full run

A researcher extending this analysis must retain, for each section, the original H&E image and physical X/Y spacing, the 10x spatial position file with barcodes, expression counts, a frozen spot-to-group CSV, the image registration transform, the full 1,280-channel Virchow2 feature grid with encoder revision and coordinate mapping, and the Bora field-model/configuration version. The spatial cluster table must have one unique row per in-tissue barcode and its native full-resolution spot center.

The historical source-download manifest and expression-clustering front ends show the original 10x samples and Giotto, Seurat and SpatialExperiment steps. They need their original R dependencies and historical tile-planning integration. A newly generated cluster table may differ from the frozen input even with the same random seed; do not compare a new mask hash with the published hash unless every upstream input and software version matches. The current Bora package freeze documents the installable software, but it does not restore absent historical Benchmark 3 caches.

For a new validation study, freeze the sections and spot clusters before mask generation, record complete-case counts, and compare boundaries with independent anatomical references. Agreement with the input spot groups measures input preservation only.
