A practical guide to the breast, colorectal and tonsil Visium examples.

Benchmark 4 asks whether image-guided refinement can turn spatial gene-expression spot groups into a registered tissue-region map. The published examples use expression groups as input. They do not demonstrate cell-level gene-expression localization or accuracy against independent anatomical masks.

1. Register 10x spots to H&E
2. Group expression profiles
3. Extract calibrated Virchow2 features
4. Refine group fields with Bora
5. Inspect mask and GeoJSON
Two reproducible routes: verify the three saved published GeoJSON outputs without a GPU (Section 2), or run a new complete R workflow from registered expression spots and H&E (Sections 4–5). The latter creates a new mask, not a copy of the historical masks.
Historical reproduction limit: the public archive does not contain every original full-resolution Virchow2 grid, frozen spot-group table and fitted field-model input. Thus a new run must not be expected to reproduce the three displayed masks bit for bit. Its expression-guided output is exploratory, with no independent anatomical boundary reference.

2 · Verify the published outputs

  1. Install Python 3.10 or newer. No Python packages, R installation or model weights are needed for this saved-output check.
  2. Clone Bora-Analysis and run the verifier from its repository root. It downloads the three GeoJSON archives from their pinned Git revision, checks compressed and uncompressed SHA256 values and sizes, and inspects group IDs and geometry types.
git clone https://github.com/tkcaccia/Bora-Analysis.git
cd Bora-Analysis
python3 methods/benchmark3/verify_published.py \
  --provenance site/visium/FULLSECTION_PROVENANCE.json

3 · Inspect what the output means

  1. Open the breast, colorectal or tonsil page.
  2. Compare the original H&E, coarse expression groups, Virchow2 response view and final mask at the full-section overview. Then inspect a matched zoom. Each zoom is a crop of the same final section mask.
  3. Use the GeoJSON inspector or download the full native-coordinate GeoJSON. Its properties.value is the anonymous group ID. Do not interpret it as a cell type or an expert tissue class.

The GeoJSON check establishes output integrity and format. It does not recompute the reported spot-centre agreement or test tissue-boundary accuracy. In breast, the published tissue support visibly omits some pale tissue; an uncolored region there is a limitation of the output.

4 · Run Bora from a clustered R object

Install the Bora R package with Bora.spatial() and its matching Python backend. Set RETICULATE_PYTHON and obtain the separately licensed Virchow2 weights. The input object must be a Seurat, Giotto or SpatialExperiment object with expression-group labels and spot positions. The positions must correspond to the full-resolution pixels of the supplied H&E, with upper-left origin. A known low-resolution coordinate system needs its measured X/Y scale factors.

library(Bora)
he <- "/data/section/registered-fullres-he.tif"
support <- "/data/section/reviewed-tissue.geojson" # precomputed H&E support
obj <- readRDS("/data/section/clustered-object.rds")

result <- Bora.spatial(
  image = he, object = obj,
  cluster_column = "KODAMA_Louvain",
  tissue_mask = support,
  model_dir = "/models/virchow2",
  source_mpp_xy = c(0.50, 0.50),
  output_dir = "/results/section-bora-v1")
result$mask      # cleaned categorical TIFF, at output_mpp_xy
result$geojson   # polygons in full-resolution H&E pixel coordinates
result$bw_images # one binary TIFF for each expression group
result$preview

For Seurat, the function reads active identities by default or a named metadata column and uses unscaled image coordinates. For Giotto it joins spatial locations to cell metadata; for SpatialExperiment it uses spatialCoords() and colData(). Spot IDs are checked before fitting, out-of-tissue positions are excluded, and contradictory groups in one Virchow2 token cause an error. The receipt records the spot-to-group mapping and output paths. This route fits a ridge head to spot labels on the same section; image-only extrapolation between and beyond spots is not an independently validated tissue classification.

5 · Start from expression counts: full R pipeline

The R pipeline script sources the released expression front end for breast/Giotto, colorectal/Seurat or tonsil/SpatialExperiment, then passes its clustered object directly to Bora.spatial(). It uses a registered image, a precomputed tissue mask, measured microscopy spacing, the licensed encoder weights and a new output directory. The historical front ends also require their documented R dependencies and wsiTools.

export RETICULATE_PYTHON=/path/to/bora-python/bin/python
Rscript methods/benchmark3/legacy_clustering/run_benchmark4.R \
  seurat /data/colorectal /data/colorectal/fullres-he.tif \
  /data/colorectal/tissue.geojson /models/virchow2 \
  /results/colorectal-v1 0.50 0.50

# Replace seurat with giotto or spatialexperiment for the other examples.
# The script performs normalization, PCA, KODAMA/Louvain spot grouping,
# full-channel Virchow2 preparation, spot-guided fitting and vector export.

Retain the original image, measured X/Y spacing, 10x barcode-position file, expression counts, tissue support, encoder revision, 1,280-channel feature grids, generated spot table, model receipt and mask/GeoJSON checksums. A new expression clustering result can change the final mask even if the random seed is the same. The script's outputs are a new analysis, not the three pinned published GeoJSONs.

For a new validation study, freeze the sections and spot clusters before mask generation, record complete-case counts, and compare boundaries with independent anatomical references. Agreement with the input spot groups measures input preservation only.
