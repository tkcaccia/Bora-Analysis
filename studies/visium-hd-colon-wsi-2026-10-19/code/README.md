## Regional and whole-slide experiments

The **conditional ROI** at native `(x=48000, y=12000, width=2048, height=2048)` uses expert polygons only to construct anonymous 90-working-pixel coarse tiles. Its reference can therefore measure *refinement of expert-derived coarse input*, not independent tissue discovery. In that ROI, the working grid is 1122 × 1122 at approximately 0.49979 µm/pixel. `prepare_roi.py`, `extract_roi_features.py` and `score_roi.py` reproduce this comparison. The corrected 25-class Neighbor context fastPLS head was refitted from the pre-existing 967 training groups under the current vendored fastPLS revision; no colon labels entered that fit.

The **unsupervised ROI** reuses the same Virchow2 spatial tokens but makes coarse groups with StandardScaler/PCA24/KMeans2, without opening the expert reference. `cluster_roi.py` creates that input; `score_roi.py --reference-case ...` reads the reference only after Bora inference.

The **full-WSI test** samples 300 spatially separated 224-working-pixel Virchow2 windows across thumbnail-identified tissue, then fits a single global StandardScaler/PCA24/KMeans6 clustering (`fit_wsi_clusters.py`). `run_wsi_geometry.py` visits 4096-native-pixel cores with 512-native-pixel halos. It reads one native crop at a time, extracts full 1280-channel Virchow2 spatial tokens at base/2×/4× physical scales, assigns 90-working-pixel coarse tiles from the frozen global clustering, applies RGB9+19 and Bora-AF, and writes the native anonymous group core to a disk-backed WSI mask. Pixel-weighted group token sums are accumulated only over non-overlapping cores. Windows with fewer than 16 eligible local tiles or one local group use an explicitly recorded coarse-palette fallback rather than fitting an invalid local RGB probability model. The entire WSI is represented in native coordinates; H&E-derived background is excluded after refinement. Two CPU-only readouts are compared without changing the frozen geometry or retraining the head: `finalize_wsi.py --stage classify` assigns one tissue class to each WSI-wide anonymous group, while `classify_window_groups.py` assigns a class to each group within a bounded 4096-pixel core. The latter avoids forcing disconnected pieces of one global cluster to share a tissue identity. Both use the same corrected Neighbor context fastPLS model. Their raw masks are scored against the annotation only after inference; this is exploratory single-slide method selection, not an untouched test estimate.

`finalize_wsi.py` cleans all final positive islands and enclosed holes strictly below 20 native pixels using 32-pixel overlap. A bright, nearly neutral scanner strip is removed from the classified mask only after Virchow2 and Bora, using `remove_background_wsi.py` (HSV saturation ≤10/255 and minimum RGB >210). `refine_background_support_wsi.py` then rejects predictions in 140.2-µm blocks with less than 1% stained pixels. These rules were chosen from the original H&E and predictions without reading the expert labels; the final area cleanup is repeated during vector fitting. Bora's `wsi_export.py` then fits each native core as a planar coverage at at most 0.75 native pixels (approximately 0.205 µm), with at least 97% per-class shape agreement and no more than 1.5% tissue-area change. Published Bora final-region cleanup runs after fitting. Each GeoJSON window is rasterized into the final disk-backed mask, so the BigTIFF/OME mask and GeoJSON agree exactly in native pixels; export never requires one whole-slide polygon object in memory. `evaluate_wsi.py` scores only singly annotated pixels in a prespecified broad ontology. The mapping includes carcinoma→tumor, intratumoral/desmoplastic stroma→stroma, normal gland→normal glandular epithelium, vessels→blood vessel, and muscle→muscle. Unmapped labels, overlaps with unmapped polygons, ambiguous mapped overlaps and unannotated tissue are excluded from quality measures but not from Virchow2 analysis. Report both the mapped-pixel count and each category's Dice/IoU; this is one external WSI, not a dataset-level estimate.

All Chiamaka GPU execution is a single bounded, fail-fast process with atomic per-window checkpoints, source/checkpoint hashes and a self-deadline. A failure stops the whole bundle; it must not trigger the next GPU case or an automatic retry. UCT HPC GPU work remains paused under the project's policy.
